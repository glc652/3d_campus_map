# 浙大城市学院 3D 校园地图

根据用户提供的 `F:\project\picture` 校园示意图、鸟瞰图、实景照片制作。

## 本地启动

双击 start.cmd，或在本目录运行 `python server.py`，浏览器打开 http://127.0.0.1:5173 。也可使用任何静态 HTTP 服务器托管 dist。
所有网页依赖与使用的图片均保存在 dist，无需访问 CDN。请通过 HTTP 服务打开，不能直接双击 index.html。

## 操作

- 左键拖动旋转、右键拖动平移、滚轮缩放；触屏单指旋转、双指缩放和平移。
- 点击楼体、地图标注或建筑目录定位建筑并查看详情。
- 支持建筑搜索、类别筛选、南北校区切换、全景复位、俯视、标注开关与自动环绕。
- “查看原始布局”可以对照校园示意图和鸟瞰图。
- “模型”在本地预览时保存 GLB 到项目 models 文件夹，其他静态服务器下触发下载。在 Blender 的“文件 > 导入 > glTF 2.0”中导入后可以精修并另存为 .blend。

## 精度与素材

建筑名称和相对位置以 fukantu.jpg 为主。照片用于图书馆几何特征与实景详情。提供的图片可能来自不同时期，因此没有自动推断现行用途或导航路线。
建筑高度、尺寸、绿化、窗户和未提供近景的立面均为示意，并非测绘或摄影测量成果。方向按校园示意图上北下南约定。
程序没有调用 Blender：本次环境没有 Blender MCP，直接用 Three.js 生成三维模型，提供 GLB 导出用于后续 Blender 编辑。

## 文件

- dist/data.js：建筑名称、类别、相对位置、示意尺寸，可继续校准。
- dist/app.js：几何、场景、交互与模型导出。
- dist/style.css：响应式界面。
- dist/assets：本次使用的原始图片副本。
- dist/vendor：Three.js 0.180.0 及所需模块，许可证同目录保留。

原始 picture 目录未修改。


## 建筑细化版（2026-09-30）
- 更新 69 处建筑/入口，另保留 2 个跑道操场和 1 处室外球场。
- 窗格、窗框、阳台、栏杆、楼梯间、女儿墙、雨棚及入口增加实体细节；构件按建筑和材质合并，降低绘制调用。
- 图书馆、问源楼、东体楼有可识别的对应照片；北校区正门参考用户照片。
- 第二食堂金属屋面照片归属待核实；其他单栋外观仍主要依据示意总图/鸟瞰图推定。不是实测重建，不代表所有建筑已达到实物还原。
- 科技综合楼按校报十二层顶平台记载修正体量；至善楼分类改为生活；慕贤楼名称依据用户鸟瞰图修正。
- 选中建筑可查看参考依据、原始来源和四个观察角度。点击照片可打开大图。

参考资料保存在 `references/photos`（51 张官网图片，包括风景、内景与地图，非 51 栋建筑的独立实景）；`references/sources.json` 记录原网址，`references/building-evidence.json` 记录每一处地点的证据情况。原图片版权归来源方。

验证：运行 `node validate-model.mjs` 检查楼体几何坐标和高度范围，并生成逐楼依据清单。浏览器点“模型”导出当前 GLB 至 `models/ZUCC-campus-schematic.glb`。上一版源码和模型保存在 `milestones/v1`。


### 近期实景参考

本轮采用学校官方账号 2024 年发布的实拍，更新文一文二连廊、晨苑店面、两处校门及风雨操场局部立面。点击建筑可看到照片、发布日期、来源与推定范围。照片下载记录位于 `references/recent/sources.json`；不是每栋楼都已取得近期全立面照片。

## 工程归档

当前地图包含75处地点。`picture/` 保存用户原始素材，`models/` 保存可导入 Blender 的 GLB，`videos/` 保存导览成片，`video-edit/` 保存六段剪辑素材、脚本与剪映草稿，`milestones/` 保留阶段版本。

运行 `npm ci` 后可执行 `node validate-model.mjs`；网页本身的依赖已经放入 `dist/vendor`，本地预览只需 Python 3 和 `python server.py`。

视频剪辑脚本与剪映草稿中部分路径来自原 Windows 工作区，换机后需重定向素材路径及本地 FFmpeg、剪映 skill 路径。历史图片的年代与建筑推定范围见参考说明，图片版权属于原作者。
